# 4. Build the labeled (gold) dataset — 3,000–5,000 examples

A. **Sampling strategy**

* Stratify by year, journal, source (PubMed vs preprint), organism (if possible).

B. **Annotation guidelines (clear, short)**

* Label `1` (positive) if the paper **reports original sequencing data** (authors performed sequencing or deposited reads). Evidence: mentions an accession (SRR/GSE/PRJNA), explicit method section describing sequencing, instrument model, or “reads were deposited in SRA/GEO/ENA”.
* Label `0` (negative) if sequencing is not performed (review, in silico analysis without new sequencing, commentary) or if it only discusses sequencing results from other papers (unless new sequencing was performed).

# 6. Model training & prediction (classify the rest)

B. **Stronger approach**

* Fine-tune SciBERT/BioBERT on the annotated 3k–5k examples for sequence classification (title+abstract). Use Hugging Face `transformers`.

# 7. Extracting names, emails, affiliations, countries (practical steps)

A. **Primary sources for contact info**

* Metadata returned by PubMed / Europe PMC may include author affiliations; rarely includes emails.
* Publisher DOI pages often include `mailto:` links in HTML (search `href="mailto:`).
* Full-text PDFs or article HTML body sometimes contain corresponding author email. Use GROBID to parse PDFs into structured metadata (authors, affiliations, email).
* ORCID / institutional pages / lab pages may provide contact emails (if available publicly).

B. **Mailto detection (safe method)**

* Fetch DOI landing page (use API or requests). Parse HTML (BeautifulSoup / lxml). Extract `<a href="mailto:...">`.
* If page is JS-rendered (email injected using JS), use headless browser (Playwright or Selenium) to render and then extract `mailto:`.
* **Regex fallback** on text: `r'[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}'` applied to full text / HTML / PDF-extracted text.

C. **PDF parsing**

* Use GROBID (recommended) for robust title/author/affiliation/email extraction. It returns structured TEI XML.
* Alternative: pdfminer + regex extraction (less accurate).

D. **Affiliation → country mapping**

* Parse affiliation text (institution, city, country). If no country, resolve institution via ROR (Research Organization Registry) or use GeoNames / heuristic lookup. OpenAlex often contains institution country.
* If affiliation is ambiguous, try matching against ROR or a list of universities + countries.

E. **Dealing with obfuscation & privacy**

* Some publishers obfuscate emails (`name[at]inst.edu`) or show contact forms. Implement heuristics to normalize obfuscated addresses, but respect site ToS and robots.txt.

F. **Provenance**

* For each extracted contact, save `extraction_method` (`publisher_html_mailto`, `pdf_grobid`, `metadata`, `institution_page`), `source_url`, `timestamp`.

**Find `mailto:` on DOI page**

```python
import requests
from bs4 import BeautifulSoup

def extract_mailto_urls(doi_url, user_agent="MyBot/1.0"):
resp = requests.get(doi_url, headers={"User-Agent": user_agent}, timeout=15)
soup = BeautifulSoup(resp.text, "html.parser")
mails = {a['href'][7:] for a in soup.find_all('a', href=True) if a['href'].lower().startswith('mailto:')}
return list(mails)
```
